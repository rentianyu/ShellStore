## [1.3.3] - 2026-11-04 【正式版】

版本号 48。

### 修复

- **深色模式下大部分文字看不清**：主题入口没有提供 Surface 容器，Compose 的默认内容色会回退成纯黑，
  凡是没显式指定颜色的文字（分类卡片标题、「全部命令」、命令卡片标题）在深底上就是黑字
  - 现在主题根节点包了一层 Surface，内容色跟随 onBackground，深浅两套自动对应
- **标签、代码块、风险色在深色下仍是浅色配色**：这组语义色原本是一套写死的浅色常量
  （浅绿底 / 浅灰底 / 近黑字），深色下浅底刺眼、字看不清
  - 拆成深、浅两套，深色改用「低亮度同色相底 + 高亮前景」，按 AA 对比度重新取色
  - 「安全」标签改为深绿底浅绿字，`shell` 等中性标签改为深灰底浅灰字，代码块改为深底浅字
  - 浅色模式的观感与 1.3.2 完全一致

### 说明

- 开关滑块的白色圆点保持不变：深色下若跟随底色会看不出边界

## [1.3.2] - 2026-11-04 【正式版】

版本号 47。

### 修复

- **搜索后滑到列表底部会退出软件**：搜索结果底部手指常压在最后一张卡片的「执行 / 打开」按钮上，
  轻点一下就会执行命令或唤起别的 App（如京东、微信），切回来时进程已被系统回收，于是表现为「直接闪退、状态全丢」
  - 现在列表停止滚动 350ms 内的点击一律忽略，正常点击不受影响
  - 卡片本身、收藏按钮、编辑按钮同样加了这个保护
- **重复条目导致的列表崩溃**：条目 id 由「分类 + 标题」算出，同一个源被添加两次、或两个源有同分类同标题时会产生完全相同的 id，
  LazyColumn 在两项同时进入可见区时会抛 "Key was already used" 直接崩溃
  - 合并订阅源时按 id 去重，弹出来源警告里会写明合并了多少条
  - 添加源时校验 URL，同一地址不再允许重复添加（已存在的会提示并直接启用）
  - 启动时自动合并历史遗留的同地址重复源

### 新增

- **崩溃日志**：「我的 › 关于」新增「崩溃日志」入口，未捕获异常会自动记录到本机（保留最近 5 份），
  可一键复制发给开发者定位。不联网、不上传，纯本地

### 说明

- 崩溃日志只覆盖 Java/Kotlin 异常；被系统直接杀进程（内存不足）或 native 崩溃抓不到

## [1.3.0] - 2026-11-03 【正式版】

版本号 45。

### 新增

- **S3 对象存储备份**：云备份页新增 S3 通道，与 WebDAV 并列，顶部一键切换
  - 兼容 Cloudflare R2（Region 填 `auto`）、AWS S3、MinIO、七牛 Kodo、阿里 OSS / 腾讯 COS 的 S3 端点
  - 支持虚拟主机风格（`bucket.endpoint/key`）与路径风格（`endpoint/bucket/key`），后者对应「路径风格」开关
  - 自实现 AWS Signature V4（只签 `host` / `x-amz-content-sha256` / `x-amz-date`），不引任何 SDK，
    签名算法用 AWS 官方测试向量验证过（GET 与 PUT 两组完整签名一致）
  - 测试连接用 HEAD 探测：200 表示已有备份可读写，404 表示认证通过、对象还没上传
- **自动备份跟随当前通道**：WebDAV 或 S3 二选一，避免一次改动上传两份、流量翻倍
- 备份内容不变：订阅源 + 收藏夹（含文件夹层级、标签、条目快照）+ 设置 + 最近使用

### 说明

- S3 的 Secret Access Key 与 WebDAV 密码一样用 KeyStore 加密只存本机，不进备份文件
- 已有的 WebDAV 配置与自动备份开关不受影响，升级后照常工作

## [1.2.0] - 2026-11-03 【正式版】

版本号 43。

### 新增

- **字号 10 级**：80% ~ 140%，拆成两行等宽档位，标题右侧显示当前百分比。
  只放大文字，控件尺寸不变
- **界面缩放 5 级**：85% / 92% / 100% / 110% / 120%。缩放作用在 density 上，
  控件与文字一起变大变小，与「字号」互不干扰；两者可叠加（例：120% 缩放 + 140% 字号）
- **WebDAV 云备份**（我的 › 备份与恢复 › WebDAV 云备份）：可配置服务器、账号、远端路径，
  支持测试连接、立即备份、从云端恢复（合并 / 覆盖两种）
- **变更后自动备份**：打开开关后，订阅源/收藏/设置/最近使用任一变更约 30 秒后自动上传，
  期间继续改动会重新计时；云端只保留最新一份快照
- 备份格式升到 `shellstore-backup/v2`：新增订阅源配置与最近使用记录，
  v1 的旧备份文件仍可导入（缺的字段跳过）

### 说明

- WebDAV 密码用 Android Keystore 的 AES/GCM 加密后只存本机；
  备份文件、云端快照、导出的 JSON 都不含密码，换机需重填一次
- 订阅源内容本身不随备份走（只备份源的地址与开关），恢复后在「订阅源」里刷新一次即可
- 字号档位由连续倍率改为 10 档：老配置按就近吸附，不会因升级跳变

## [1.0.0] - 2026-11-03 【正式版】

版本号 39。首个正式版。

### 功能

- **内容浏览**：分类宫格 + 全部条目 + 全字段搜索，支持按类型筛选
- **七类条目**：shell / script / URL Scheme / Intent / Activity / Service / Broadcast
- **详情与执行**：`{占位符}` 实时重算、一键复制、shell 与脚本可直接执行、
  Intent 类可打开/发送/启动，并显示等价的 adb 命令便于在电脑复现
- **收藏**：多级文件夹、标签、长按拖拽排序、多选批量操作；收藏存的是快照，
  源被删或改了内容仍在
- **订阅源**：官方源、在线源、本地导入，17 条线路自动降级，ETag 增量更新；
  「小贝塔订阅源」一栏列出可选的系列源，清单本身是 SMD，新增源无需升级 App
- **导入导出**：JSON 备份与恢复、导出为订阅源（SMD）、粘贴导入、单条复制为 SMD
- **其他**：应用内检查更新与安装、字号与字体调节、深浅色主题、最近使用、搜索历史

### 合规

- 首次启动协议同意页：《用户协议》与《隐私政策》独立成文，提供「同意」与「不同意」
  两个选择，不默认勾选；不同意不会强制退出，进入离线基础模式
- 同意前不发生任何联网行为；设置页与关于页均提供协议入口
- 隐私政策如实说明：不收集个人信息、不集成任何第三方 SDK、只申请三项系统权限、
  数据全部保存在本机、无自建服务端

### 说明

- 本软件不提供、不存储、不分发任何订阅源内容；订阅源由用户自行添加并负责
- 命令由用户自行决定是否执行，执行后果自负
